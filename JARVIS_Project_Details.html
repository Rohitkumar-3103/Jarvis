3. Arc Reactor HUD & Dynamic Assistant States

The central synapse visualizer reacts dynamically across 6 distinct operational states:

STATE 01 Standby (Idle)
  • Visual Core: Rhythmic, slow pulsing cyan glow at 0.5Hz.
  • System Meaning: Workstation is armed, listening daemon ready.
  • Trigger: Startup completion or post-response rest.
STATE 02 Listening
  • Visual Core: Active red/cyan audio wave frequency oscillation.
  • System Meaning: Web Speech API active, receiving en-IN/hi-IN audio.
  • Trigger: Arc Reactor click or floating microphone dock activation.
STATE 03 Thinking / Synapsing
  • Visual Core: Rapid concentric ring matrix rotation in violet/magenta.
  • System Meaning: Google Gemini reasoning or local knowledge synthesis.
  • Trigger: Query submission (voice or terminal text bar).
STATE 04 Tool Execution
  • Visual Core: High-velocity orbital pulse with amber warning accents.
  • System Meaning: Running Playwright, WhatsApp send, or Python sandbox.
  • Trigger: Dispatching action via actions/ executor.
STATE 05 Responding / Vocalizing
  • Visual Core: Kinetic emerald ripple waves synchronized with speech audio.
  • System Meaning: SpeechSynthesisUtterance active; chat bubble streaming.
  • Trigger: TTS playback of assistant answer.
STATE 06 Success / Confirmation
  • Visual Core: Instantaneous bright emerald flash and chime.
  • System Meaning: Target action completed successfully.
  • Trigger: App opened, volume set, message dispatched, screenshot taken.

9. Installation, Quickstart & Launch Guide

STEP 1 Prerequisites

Windows 10/11, Python 3.12+ (or 3.10+), modern browser (Chrome, Edge, Brave).

STEP 2 Dependencies
pip install -r requirements.txt
STEP 3 Single-Command Full-Stack Launch

Starts the Flask backend on Port 5000 and the Tactical Web HUD on Port 8080 simultaneously:

py -3.12 run_dashboard.py # Or standard launcher: python run_dashboard.py
STEP 4 Access Operating System in Browser

Open http://127.0.0.1:8080. Enter your Gemini API key in Settings or immediately use the built-in offline fallback engine.
